# Mavuri - API Mercado Livre

Este projeto possui frontend estático e um proxy serverless.

## Publicação

1. Envie todos os arquivos desta pasta para o repositório `mavurioficial/mavuri-api-test`, substituindo os arquivos existentes.
2. Entre em https://vercel.com e conecte sua conta do GitHub.
3. Clique em **Add New Project**.
4. Importe o repositório `mavurioficial/mavuri-api-test`.
5. Clique em **Deploy**.

Depois disso, abra a URL gerada pela Vercel. O frontend e o endpoint `/api/meli` ficarão no mesmo domínio.

## Segurança

Não coloque `client_secret` ou tokens permanentes no GitHub.
